# CREATIVE ZONE · terminal interativo

Site do **Live Terminal** do perfil [Forum-CreativeZone](https://github.com/Forum-CreativeZone), publicado em
**https://forum-creativezone.github.io**.

- `index.html`: o terminal inteiro (HTML + CSS + JS, sem build). Textos, links e o `whoami` ficam no bloco `CONFIG` no topo do script.
- `miguel-ascii.svg`: retrato ASCII usado pelo comando `portrait`.
- Os números (contribuições, sequências, gráfico) vêm de `stats.json` no repositório do perfil, que um GitHub Action atualiza todo dia.

Comandos: `help`, `whoami`, `contributions`, `stats`, `projects`, `portrait`, `social`, `github`, `linkedin`, `instagram`, `email`, `neofetch`, `matrix`, `banner`, `date`, `echo`, `history`, `clear`.
