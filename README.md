# CREATIVE ZONE · terminal interativo

Site do **Live Terminal** do perfil [Forum-CreativeZone](https://github.com/Forum-CreativeZone), publicado em
**https://forum-creativezone.github.io**.

- `index.html`: o terminal inteiro (HTML + CSS + JS, sem build). Textos, projetos, stack e links vêm de `content/profile.json` no repositório do perfil, a mesma fonte do README (com uma cópia embutida como reserva).
- `miguel-ascii.svg`: retrato ASCII gravado a laser, usado pelo comando `portrait`.
- Os números (contribuições, sequências, gráfico) vêm de `stats.json` no repositório do perfil, que um GitHub Action atualiza todo dia.

Comandos: `help`, `whoami`, `projects`, `repos`, `creativezone`, `stack`, `contributions`, `stats`, `portrait`, `social`, `forum`, `github`, `linkedin`, `instagram`, `email`, `neofetch`, `matrix`, `banner`, `date`, `echo`, `history`, `clear`.
